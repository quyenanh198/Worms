Worms

Chơi trên trình duyệt: mở game. Muốn mượt hơn thì cài app.

Android

Tải Worms.apk
  1. Mở file vừa tải. Nếu Android hỏi, cho phép trình duyệt cài ứng dụng không rõ nguồn.
  2. Mở app, đăng nhập bằng tài khoản Chat.

iPhone, iPad

Chơi trên Safari. Bấm nút Chia sẻ → Thêm vào Màn hình chính để mở toàn màn hình như app.

Máy tính

Windows macOS Linux

App chưa được ký. Windows: bấm "More info" → "Run anyway". macOS: chuột phải vào app → Open lần đầu.
